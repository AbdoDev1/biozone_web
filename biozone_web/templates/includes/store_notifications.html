{# Shared store notification layer (toast) — display only. Binding rules: - Every message goes through textContent; there is no HTML sink here. - The toast layer never decides business semantics: callers pass an already-curated safe string and a type. API error-code mapping lives in the calling page (allowlisted codes only). - Errors that block an action (order confirmation, form submit) keep their persistent inline message near the action. Toast is used only for transient success/info/warning and for failures with no inline home (e.g. localStorage write failure). - Auto-dismiss applies to success/info only. Errors are persistent by default and are closed manually. - A visible toast with the same type+title+message+key is reused instead of duplicated; dismissal frees the slot for a later genuine event. - Timers pause on hover/focus; prefers-reduced-motion disables motion; max 3 visible, transient toasts evicted before persistent errors. - Fixed at top-center, RTL, below the sticky header (z-index 90), and the stack itself never intercepts pointer events. API: BzNotify.success(message, opts) BzNotify.info(message, opts) BzNotify.warning(message, opts) BzNotify.error(message, opts) BzNotify.show(type, message, opts) BzNotify.dismiss(element) opts = {title, duration, persistent, key} #}
